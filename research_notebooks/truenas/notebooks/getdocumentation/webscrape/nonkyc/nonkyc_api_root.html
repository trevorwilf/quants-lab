Datetime Formatting

Timestamps returned as String are in ISO8601 format in UTC. Example: "2021-12-01T00:00:00Z" or "2021-12-01T00:00:00.000Z". If a timestamp is returned as a Number, then that is a Unix timestamp in milliseconds.

Precision Formatting

All finance data such as price, quantity, and fee should be string representation of arbitrary precision numbers to prevent floating point issues. Example: "9823.23932892". Integers should be represented in integer format and not a string.

Authentication

There are two authentication methods available for you to choose from. Basic Auth & HmacSha256 Signed Requests. Signed requests are more secure as it prevents replay attacks and accidental duplicate calls. to make authenticated requests you must include the apiKey (public api key), nonce(Current timestamp in unix milliseconds) and signature in your request headers (X-API-KEY, X-API-NONCE and X-API-SIGN).

The signature is created by hashing the following string using the HMAC-SHA256 algorithm. The API secret (apiSecret) is used as the key for the HMAC calculation

  • For Get requests : Concatenate the API Key, Request URL and Nonce into a single string.

  • For Post requests : Concatenate the API Key, Request URL,Request Body and Nonce into a single string.

a python example showcasing how to send a signed request

import json
import requests
from time import time
import hashlib
import hmac

apiKey = "Your Api Key"
secretKey = "Your Secret key"

url = 'https://api.nonkyc.io/api/v2/cancelorder'
nonce = str(int(time()*1e3))

req_body =  {'id' :'5845454765457',}
json_body_data = json.dumps(req_body,separators=(',',':'))

data_to_sign = f"{apiKey}{url}{json_body_data}{nonce}"
signature = hmac.new(secretKey.encode(), data_to_sign.encode(),hashlib.sha256).hexdigest()

headers =  {
"X-API-KEY": apiKey,
"X-API-NONCE": nonce,
"X-API-SIGN": signature,
"Content-Type": "application/json"
}
response = requests.post(url, data=json_body_data, headers=headers)
